# Ming OS 26.4.1 RC4 用户验收问题记录（2026-08-30）

## 记录范围

本记录来自用户在新 RC4 安装完成后的桌面验收。问题先记录，后续再按“复现 -> 定位 -> 修复 -> 回归”处理。本记录不把截图或静态源码检查当作问题已修复的证据。

## 新增问题

1. **窗口无法完全全屏**
   - 现象：应用窗口进入全屏后仍保留窗口边界或未覆盖整个工作区。
   - 影响：无法获得真正的全屏使用体验，可能与 Dock、窗口管理器或合成器层级有关。
   - 状态：待复现；需分别检查最大化、窗口全屏和应用原生全屏。

2. **Ming 应用商店不可用且卡片布局效率低**
   - 现象：商店仍不可用；当前界面一个软件占用一整行的大面积区域，搜索和浏览效率低。
   - 影响：无法完成软件发现和安装；不符合应用卡片网格的设计目标。
   - 状态：待复现；需记录 Provider 状态、网络请求、缓存回退和安装按钮真实状态。

3. **终端没有关闭键**
   - 现象：终端窗口标题栏缺少可见的关闭按钮或关闭操作不可用。
   - 影响：用户无法通过窗口控件正常关闭终端。
   - 状态：待复现；需检查 Xfwm 标题栏、终端窗口类型和主题配置。

4. **Xiahai Xiaoming 仍不可用**
   - 现象：点击 Xiahai Xiaoming 后无法正常使用。
   - 影响：预装应用启动链仍未通过真实用户验收。
   - 状态：待复现；需保留启动日志，确认是否为沙盒权限、依赖缺失、窗口超时或桌面入口问题。

5. **小组件折叠/展开状态仍异常**
   - 现象：折叠状态仍像旧样式；展开后出现重复内容、重叠和位置漂移。
   - 影响：状态组件与已确认的 A 方案不一致，且可能遮挡桌面内容。
   - 状态：待复现；需检查唯一实例、固定几何、Win 键/按钮双向切换和展开动画状态机。

6. **桌面右键菜单操作无响应**
   - 现象：桌面空白处右键后点击菜单选项没有任何反应。
   - 影响：无法新建文件/文件夹或执行复制、移动、重命名等基础操作。
   - 状态：待复现；需检查菜单动作是否调用受控入口、工作目录是否正确以及错误是否写入日志。

7. **设置中的校时服务仍显示异常**
   - 现象：设置页面仍报告校时服务异常。
   - 影响：无法区分网络等待、服务未启动、DBus 不可用和真实失败。
   - 状态：待复现；需读取校时 helper 的结构化状态和实际 systemd/DBus 返回值。
