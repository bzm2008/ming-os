# Ming OS Ming Mint 视觉统一与桌面布局改造

## 目标

统一 Ming OS 的窗口、控件、终端、通知、小组件、Dock 和核心应用图标，减少 Xfce 原版视觉残留，同时修复应用抽屉从 Dock 顶部展开、Dock 不紧凑或遮挡窗口的问题。当前阶段不构建 ISO；保留现有 RC4 工作树改动。

## 视觉系统

- 使用 `Ming Mint` 作为 GTK3/GTK4、Xfwm4、终端、通知、小组件和 Plank 的统一浅色主题。
- 窗口标题栏约 32px、圆角约 10px；左侧显示应用图标和标题，右侧保留最小化、最大化、关闭按钮。
- 默认字体为 Noto Sans CJK SC，正文 14px、行高约 1.45、控件间距 8px。
- 文字区域使用不透明或高对比背景，终端、通知、错误弹窗和小组件不允许文字直接叠在壁纸上。
- 深浅主题切换只更新颜色和主题资源，不改变窗口位置、控件行为或启动路径；旧 Xfce/旧 Ming 主题配置通过迁移函数更新。

## 抽屉与 Dock

- 应用抽屉以工作区底部为锚点，从底部面板向上展开；动画只改变 Y 坐标，不以 Dock 窗口顶部为起点。
- 抽屉和 Dock 均保留固定间距，抽屉打开时 Dock 仍独立可操作；普通窗口和全屏窗口不预留永久底部空白，也不被 Dock 遮挡。
- Dock 保持居中，使用约 32px 图标、紧凑内边距、低幅度缩放和约 12px 底部留白。
- 会话协调器和 watchdog 必须保证唯一应用抽屉、唯一 Plank 和唯一相关窗口；低资源/软件渲染环境关闭高成本动画但保留布局。

## 图标系统

- 重绘设置、文件、终端、应用抽屉、更新、控制中心、Spark、Papyrus、Xiahai 等核心和自带应用图标。
- 以透明背景 SVG 为主，提供透明 PNG 回退和 24/32/48px 尺寸变体；统一扁平笔画与 Ming Mint 色板，不使用渐变或不透明底板。
- 桌面、Dock、应用抽屉和启动代理引用同一图标名，缺失时使用单一系统回退图标。
- 第三方应用图标不强行替换，避免升级覆盖；去重逻辑保证同一应用只保留一个可启动入口。

## 服务器部署边界

- 只部署已经验证的 staging 和生产 API/诊断路由，不修改 OTA 签名清单、生产私钥或官网内容。
- SSH 使用 `scallion-admin-prod`，实际用户 `scallion-admin`，目标 `39.106.98.221:7802`；使用无密码 sudo 完成 Nginx/PM2 操作，不直连 root。
- 部署过程使用版本目录和备份，完成原子切换、`nginx -t`、PM2 reload 及 API 健康检查；失败时恢复上一版本并重复检查。

## 验收

- 源码测试覆盖主题键值、标题栏参数、背景不透明度、抽屉底部坐标、Dock 唯一性/居中/窗口类型和图标引用一致性。
- VM 验收设置、文件、终端、Spark、更新、应用抽屉、Dock、最大化、全屏、最小化恢复及低资源模式。
- 服务器验收记录部署版本、PM2/Nginx 状态、诊断上传、管理员查询和 OTA API HTTP 状态/JSON schema；任一失败都验证回滚。
