# Ming Mint 小组件与全屏 Dock 设计规格

## 目标

将右上角状态小组件收敛为短胶囊：收起时只显示时间、日期、Wi-Fi 状态，以及在可移动设备上显示的电池状态；使用透明 Ming 标志和小箭头展开完整控制面板。展开/收起支持鼠标、触控和 Win 键。全屏窗口和应用抽屉打开时，Dock 不得占用内容平面或遮挡窗口。

## 视觉与布局

- 收起态顺序固定为：时间、日期、Wi-Fi 状态图标、可选电池状态、Ming 标志 + 箭头。
- 台式机不显示电池占位；笔记本/平板检测到电源设备后显示电量和充电/放电状态。
- 展开面板保留 Wi-Fi、蓝牙、亮度、音量、通知、设置、电源，以及内存、CPU、网速三项资源指标。
- 面板使用不透明 Ming Mint 背景；低资源模式关闭阴影和动画但不移除控件。
- 收起态和展开态顶部间距继续不超过 8px。

## 交互

- 点击胶囊或 Ming 标志箭头切换展开状态。
- Win 键切换展开/收起；快捷键只在桌面会话激活时生效，不抢占文本输入窗口。
- 展开默认使用短距离向下滑入 + 淡入；检测到 reduced-motion、软件渲染或低内存策略时直接切换或仅淡入。
- 资源指标收起时只保留低频内存摘要，展开时采样内存、CPU、网速。

## Dock 与全屏

- 普通窗口：Plank 保持唯一、居中、底部留白和悬停放大。
- 全屏窗口：检测到 `_NET_WM_STATE_FULLSCREEN` 后将 Dock 隐藏到全屏窗口下方，不预留底部工作区高度；退出全屏后恢复。
- 应用抽屉：抽屉窗口使用底部工作区锚点，但不提升 Dock 层级；抽屉完全展开时 Dock 下沉或隐藏，关闭后恢复。
- Dock 的层级策略由会话协调器统一管理，禁止抽屉、Dock 和桌面代理互相重复拉起。

## 资源与兼容性

- Ming 标志使用透明 SVG 资源，避免白底图片在浅色/深色主题中出现空白块。
- 电池状态读取失败时隐藏电池区域并记录诊断，不显示伪造百分比。
- Win 键监听失败时保留鼠标/触控入口，并记录可读日志；不得导致桌面会话退出。

## 验收契约

- 静态测试验证短胶囊字段顺序、SVG 资源、设备电池分支、Win 键绑定和 reduced-motion 分支。
- GTK 逻辑测试验证点击/键盘切换、收起后 expanded 子树不可见且高度为零、资源采样按状态降频。
- Dock 测试验证全屏/抽屉状态下隐藏或下沉，不预留底部黑条，退出状态恢复唯一 Plank。
